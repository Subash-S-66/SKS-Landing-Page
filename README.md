## 🚀 Featured Projects

### 🎬 [ClipForge] AI YouTube Automation SaaS
*A full-scale automation pipeline that converts text into fully edited videos, complete with scripts, voiceovers, and auto-uploads.*

- **Tech Stack:** ![Next.js](https://img.shields.io/badge/-Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white) ![Express](https://img.shields.io/badge/-Express-000000?style=flat-square&logo=express&logoColor=white) ![Python](https://img.shields.io/badge/-Python-14354C?style=flat-square&logo=python&logoColor=white) ![Redis](https://img.shields.io/badge/-Redis-DC382D?style=flat-square&logo=redis&logoColor=white) ![BullMQ](https://img.shields.io/badge/-BullMQ-FF4F00?style=flat-square&logoColor=white) ![Razorpay](https://img.shields.io/badge/-Razorpay-02042B?style=flat-square&logo=razorpay&logoColor=3395FF)
- **Highlights:**
  - Designed a multi-service architecture offloading heavy video rendering to isolated Python workers.
  - Implemented **Redis + BullMQ** for resilient distributed job queues, tracking render progress in real-time.
  - Fully integrated Razorpay subscription logic with a dynamic credit consumption system.
  - Deployed via comprehensive CI/CD pipelines (GitHub Actions) with cross-platform targets (PWA, APK, EXE).

### 🤟 [Sign2Text] Real-Time Sign Language → Text System
*An ultra-low latency machine learning pipeline translating sign language video feeds into readable text in real-time.*

- **Tech Stack:** ![Python](https://img.shields.io/badge/-Python-14354C?style=flat-square&logo=python&logoColor=white) ![WebSockets](https://img.shields.io/badge/-WebSockets-010101?style=flat-square&logo=socketdotio&logoColor=white) ![MediaPipe](https://img.shields.io/badge/-MediaPipe-00A67E?style=flat-square&logoColor=white) ![ONNX](https://img.shields.io/badge/-ONNX-005CED?style=flat-square&logo=onnx&logoColor=white)
- **Highlights:**
  - Engineered a **WebSocket-based streaming server** processing camera feeds at ~15 FPS.
  - Utilized MediaPipe for extracting 263 precise hand and body landmarks per frame.
  - Optimized sequence predictions using an **LSTM (ONNX)** model with sliding window and stabilization logic.
  - Achieved **<250ms latency** with an overall translation accuracy of ~85%.
